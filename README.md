# 김나영내과의원 홈페이지

GitHub Pages로 운영하는 병원 홈페이지입니다.
공지사항, 진료시간, 휴진일은 **홈페이지에서 관리자 로그인 후 직접** 고칠 수 있고, 글은 병원 구글 시트에 저장됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지 전체 (디자인, 내용, 관리자 기능) |
| `apps-script/Code.gs` | 구글 시트 연결 코드. 시트의 Apps Script에 붙여 넣는 용도이며, 홈페이지에서 직접 쓰이지는 않습니다 |

---

## 설치 순서 (처음 한 번)

### 1. 구글 시트 만들기 (병원 구글 계정)
1. [sheets.google.com](https://sheets.google.com)에서 **빈 스프레드시트**를 만들고 이름을 `김나영내과 홈페이지`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기의 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 병원 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용. 병원 계정이 직접 만든 코드라서 나오는 안내입니다.
   - 시트로 돌아가면 `공지사항`, `진료시간`, `휴진일` 탭이 생겨 있습니다.
   - 구글 드라이브에 `김나영내과 홈페이지 사진` 폴더도 함께 생깁니다. 공지에 첨부한 사진이 여기에 저장되니 **지우거나 옮기지 마세요.**

### 2. 관리자 비밀번호 정하기
1. Apps Script 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**를 누릅니다.
2. 속성: `ADMIN_PASSWORD`, 값: 사용할 비밀번호(8자 이상 권장)를 넣고 저장합니다.
   - 비밀번호는 이 화면에만 저장되고 홈페이지 코드에는 들어가지 않습니다.
   - 바꾸고 싶을 때도 여기서 값만 고치면 됩니다.

### 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙) → **웹 앱**을 고릅니다.
3. 실행 사용자: **나**, 액세스 권한이 있는 사용자: **모든 사용자**로 설정합니다.
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. `index.html`에서 `const API_URL = '';` 따옴표 안에 이 주소를 넣습니다.

> `Code.gs`를 나중에 고쳤다면 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 주소는 그대로 유지됩니다.

### 4. GitHub에 올리기
1. GitHub에서 **New repository**를 누르고, 이름(예: `homepage`)을 정해 **Public**으로 만듭니다.
2. **uploading an existing file**을 눌러 `index.html`, `README.md`, `apps-script` 폴더를 끌어다 놓고 **Commit changes**를 누릅니다.
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 정하고 저장합니다.
4. 1~2분 뒤 `https://계정이름.github.io/homepage/`에서 열리는지 확인합니다.

### 5. 도메인 연결 (가비아 기준)
1. 가비아 **My가비아 → 도메인 → DNS 관리 → 설정**에서 아래 레코드를 추가합니다.

   | 타입 | 호스트 | 값 |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `계정이름.github.io.` |

2. GitHub 저장소 **Settings → Pages → Custom domain**에 도메인(예: `kimnayoung.kr`)을 입력하고 저장합니다.
3. 반영되면(보통 수십 분, 길게는 하루) **Enforce HTTPS**에 체크합니다.

### 6. 확인
- [ ] 휴대폰과 PC에서 도메인 주소로 열린다
- [ ] 맨 아래 **관리자** → 비밀번호 입력 → 공지를 올리면 홈페이지와 구글 시트에 같이 생긴다
- [ ] 진료시간을 바꾸면 진료시간 표와 첫 화면의 '지금 진료 중' 표시가 바뀐다
- [ ] 네이버 플레이스 홈페이지 칸에 새 주소를 등록했다

## 평소 사용법

- **공지 올리기**: 홈페이지 맨 아래 `관리자` → 비밀번호 → 공지사항의 **+ 공지 쓰기**
- **사진 첨부**: 공지 쓰기 창의 **사진 첨부**를 누르세요. 휴대폰에서는 갤러리나 카메라를 고를 수 있습니다.
  - 공지 하나에 최대 5장까지 올릴 수 있습니다. 큰 사진은 자동으로 줄여서 올라갑니다.
  - 사진만 올리고 내용을 비워 둬도 됩니다. 포스터를 올릴 때 편합니다.
  - 수정 창에서 사진의 **×**를 누르면 빠지고, 공지를 삭제하면 사진도 드라이브 휴지통으로 이동합니다.
- **수정·삭제·고정**: 공지 제목을 눌러 펼치면 아래에 버튼이 있습니다.
- **진료시간·휴진일**: 진료시간 표 아래 **진료시간 수정**, **휴진일 관리**
- 로그인은 8시간 유지되고, 창을 닫으면 풀립니다.
- 비밀번호를 10번 틀리면 10분 동안 로그인이 막힙니다.
- 구글 시트에서 직접 고쳐도 홈페이지에 반영됩니다. 시트에서 공지를 추가할 때는 **id 칸은 비워 두세요**. 자동으로 채워집니다.

## 주의
- 구글 시트에는 **홈페이지에 공개되는 내용만** 넣으세요. 이 시트 내용은 누구나 볼 수 있는 홈페이지에 그대로 나옵니다.
- 첨부한 사진은 **링크가 있는 누구나 볼 수 있게** 공유됩니다. 환자 얼굴이나 진료 기록, 처방전처럼 개인정보가 담긴 사진은 올리지 마세요.
- 병원 계정이 회사용 구글 워크스페이스 계정이면 '링크 공유'가 막혀 있을 수 있습니다. 이때는 사진을 올릴 때 "사진 공유 설정이 막혀 있습니다"라는 안내가 나옵니다. 일반 지메일 계정을 쓰면 이런 문제가 없습니다.
- 병원 소개, 의료진, 오시는 길은 `index.html`에 직접 들어 있어서, 바꾸려면 파일을 고쳐 다시 올려야 합니다.
